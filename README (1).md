# ✈️ Airline Dashboard - Power BI Project

## 📌 Project Overview

This Power BI dashboard provides an interactive analysis of airline operations, passenger traffic, flight performance, delays, airports, aircraft utilization, and cancellations. The report enables users to monitor KPIs, identify trends, and make data-driven decisions using dynamic filters and visualizations.

---
